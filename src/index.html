자막 소스

자동은 영상에 딸린 한국어 자막(트랙)을 먼저 쓰고, 없으면 Kairan → Csora → Anissia 순서로 찾습니다. 다른 소스를 고르면 그 소스를 먼저 찾습니다. 다른 언어 트랙과 Jimaku는 플레이어 설정에서 고릅니다.

한국어 제목 검색

Re:Anime·Animenosub·Miruro 작품의 한국어 제목을 TMDB, AniList, Wikidata 순으로 찾아 한국어로 보여 주고 Kairan·Csora·Anissia 자막을 검색합니다. TMDB가 가장 많은 작품을 찾으며, API 키가 있어야 사용됩니다.

TMDB API 키

themoviedb.org 설정 > API에서 발급한 API 키(v3) 또는 읽기 액세스 토큰을 넣을 수 있습니다.

This product uses the TMDB API but is not endorsed or certified by TMDB.

자막 자동 번역

Re:Anime·Miruro 자막 트랙과 Jimaku 일본어 자막을 한국어로 번역합니다. 플레이어 설정의 Gemini 번역 · 로컬 AI 번역 버튼으로 번역하고, 번역한 자막은 저장되어 다시 볼 때 바로 적용됩니다. 한쪽을 쓸 수 없으면(키나 모델이 없거나 Gemini 무료 사용량을 다 쓴 경우) 준비된 다른 쪽이 이어서 번역합니다.

Gemini API 키

aistudio.google.com에서 발급한 API 키를 넣어 주세요.

Gemini 모델

키를 저장하면 쓸 수 있는 모델을 불러와 최신 Flash 모델을 고릅니다.

로컬 AI 모델 (llama.cpp)

인터넷 없이 이 PC에서 번역합니다. 처음 번역할 때 llama.cpp(약 33MB)를 함께 받으며, 그래픽카드가 있으면 그래픽카드로, 없으면 CPU로 돌아갑니다.

Jimaku 자막 자동 번역

한국어 트랙도 온라인 한국어 자막도 없으면 그 회차의 Jimaku 일본어 자막을 알아서 받아 번역합니다. 플레이어에서 Jimaku 파일을 직접 골라도 같습니다. 번역이 끝날 때까지는 일본어 자막이 나옵니다. 끄기를 고르면 Jimaku를 알아서 받지 않고, 플레이어의 번역 버튼을 눌렀을 때만 번역합니다. 다운로드한 자막 트랙은 Gemini 키가 있으면 Gemini로, 없으면 로컬 AI로 번역합니다.
