없으면 AI가 번역

Jimaku 일본어 자막이나 사이트의 일본어·영어 트랙을 번역합니다. 보고 있는 장면부터 번역해 번역된 줄은 바로 한국어로 바뀌고, 다음 화는 보는 동안 미리 번역해 둡니다.

  • 번역 API: Gemini · OpenAI · DeepL · Qwen · Claude
  • 내 PC의 로컬 AI: Gemma 4 · Aya · Hy-MT2

내려받아 오프라인으로

회차를 자막 · OP/ED 구간까지 함께 저장해 인터넷 없이도 그대로 봅니다. 외장하드로 옮겨도 저장 폴더만 바꾸면 다시 이어집니다.

휴대폰과 이어서 보기

내 목록과 시청 기록(이어 보기 위치 포함)을 Android 앱과 맞춥니다. 데이터는 내가 직접 만든 서버에만 저장됩니다.

  • LilacAnime 서버를 Vercel에 한 번 배포
  • 앱을 열 때, 5분마다, 바뀐 직후 자동 동기화

설치

설치한 뒤에는 새 버전이 나오면 앱이 알려 주고, 설정 > 업데이트 · 정보에서 바로 받을 수 있습니다.

LilacAnime-Setup.exe
  1. 받은 설치 파일을 실행합니다. Windows 10 / 11을 지원합니다.
  2. 설치 위치를 고르고 설치합니다. 바탕 화면에 바로가기가 생깁니다.
Apple Silicon (M1 이상) Intel
  1. Apple 메뉴 > 이 Mac에 관하여에서 칩을 확인하고 맞는 파일을 받습니다.
  2. 받은 .dmg를 열고 LilacAnime을 응용 프로그램 폴더로 끌어 놓습니다.
  3. 처음 열 때 "악성 코드가 없음을 확인할 수 없습니다"가 나오면 완료를 누른 뒤 시스템 설정 > 개인정보 보호 및 보안의 그래도 열기를 누릅니다.

그래도 열리지 않으면 터미널에서 xattr -cr /Applications/LilacAnime.app을 실행한 뒤 다시 엽니다.

.deb (x64) arm64
  1. Ubuntu · Debian · Linux Mint 등 .deb를 쓰는 배포판에서 설치할 수 있습니다.
  2. 터미널에서 설치합니다: sudo apt install ./LilacAnime-linux-amd64.deb (arm64면 그 파일 이름). 앱 메뉴에 LilacAnime이 생깁니다.

지우려면 sudo apt remove lilacanime-desktop. 한국어 자막에는 fonts-noto-cjk 또는 fonts-nanum을 권장합니다.

설치하고 가장 먼저

TMDB 키 넣기

한국어 자막을 찾는 데 가장 중요한 설정입니다. RE:Anime · Miruro · Animenosub는 작품 제목이 영어라서, 한국어 자막(Kairan · Csora · Anissia)을 찾으려면 한국어 제목을 알아야 합니다. TMDB 키가 있으면 훨씬 많은 작품의 한국어 제목을 찾아 자막이 더 많이 붙고, 제목과 줄거리도 한국어로 나옵니다. 키는 무료이고 PC 브라우저로 5분쯤 걸립니다.

1

TMDB에서 키 받기

  1. themoviedb.org에 가입하고, 받은 메일의 링크를 눌러 인증합니다.
  2. 로그인한 뒤 설정 > API로 갑니다.
  3. Create / Request an API Key를 누르고 Developer를 고른 뒤 약관에 동의합니다.
  4. 신청서를 채웁니다. 용도는 개인(Personal), 앱 이름은 LilacAnime, 주소는 아무 주소(예: GitHub 주소), 설명은 "개인용 애니 제목 검색"이면 됩니다.
  5. 바로 나오는 API 키(영문 · 숫자 32자)를 복사합니다. 그 아래 긴 읽기 액세스 토큰을 써도 됩니다.

TMDB 신청 화면은 휴대폰에서 잘 안 되니 PC로 해 주세요.

2

앱에 넣기

  1. 오른쪽 위 설정(톱니바퀴)을 누릅니다.
  2. 왼쪽에서 한국어 제목 검색을 고릅니다.
  3. TMDB API 키 칸에 붙여 넣고 저장을 누릅니다. "TMDB API 키를 사용 중입니다"가 나오면 성공입니다.
  4. 아래 칸에서 한국어 제목을 찾아 갑니다. 처음엔 몇 분 걸리고, 그동안에도 앱은 그대로 쓸 수 있습니다.
잘 안 될 때
"저장하지 못했습니다" · "TMDB API 키나 사용 권한을 확인해 주세요"
키를 앞뒤 공백 없이 다시 복사해 넣어 보세요. API 키 대신 읽기 액세스 토큰을 넣어도 됩니다.
"TMDB에 연결하지 못했어요" · "응답 시간이 초과됐어요"
인터넷이나 TMDB 서버 문제입니다. 앱이 켜져 있으면 30분 뒤 알아서 다시 시도합니다.
"TMDB 요청 제한으로 잠시 쉬는 중"
정상입니다. 잠시 기다렸다가 이어서 찾습니다.
숫자가 전체 작품 수까지 안 올라가요
표시되는 숫자는 진행률이 아니라 한국어 제목을 찾은 작품 수입니다. 한국어 제목이 없는 작품도 있어서 정상입니다.

사용법

화면 속 번호가 아래 순서와 같습니다.

  1. 위쪽 검색창에 제목을 한국어로 입력하고 Enter를 누릅니다.
  2. 또는 이번 시즌 추천에서 고릅니다. 작은 포스터는 그 작품으로 바꾸고, 큰 포스터는 작품 화면을 엽니다.
  3. 전체 > 상세 필터에서 장르 · 연도 · 상태 같은 조건으로 찾아봅니다.
  1. ○화 재생은 첫 화부터, 본 적이 있으면 이어보기로 멈춘 곳부터 재생합니다.
  2. 보고 싶은 회차를 골라 눌러도 됩니다.
  3. 회차 옆 버튼은 그 회차만 내려받습니다. 받은 회차는 휴지통 버튼으로 지웁니다.
  4. 전체 저장은 모든 회차를 내려받습니다.

자막은 앱이 알아서 찾아 입힙니다. 홈의 이어서 보기나 위쪽 시청기록에서 멈춘 곳부터 이어집니다.

  1. 재생 화면 오른쪽 위의 플레이어 설정을 누릅니다.
  2. 자막 탭을 엽니다.
  3. 자막 가져올 곳: 다른 블로그를 골라 보거나, 다른 회차 자막이 나오면 AI 번역을 누릅니다.
  4. 자막 제작자 · 트랙: 다른 분의 자막이나 사이트의 다른 언어 트랙으로 바꿉니다.
  5. 한국어 자막 다시 찾기 · 내 PC의 자막 파일 열기(ASS · SSA · SRT · VTT · SMI)
  1. 플레이어 설정에서 자막 모양 탭을 엽니다.
  2. 자막 크기 · 줄 간격 · 높이: 막대를 끌어 바꿉니다.
  3. 자막 타이밍: 자막이 늦으면 빠르게, 먼저 나오면 늦게. 보면서 Z · X 키로도 바꿉니다.
  4. 글꼴: 내 PC의 글꼴 파일(TTF · OTF)을 고르면 자막이 그 글꼴로 나옵니다.

싱크가 어긋나면 앱이 영상 음성에 맞춰 자동으로 맞춥니다. 플레이어 위 알림의 되돌리기로 원래대로 돌아갈 수 있어요.

한국어 자막이 없는 작품도 보려면 둘 중 하나만 준비하면 됩니다.

  1. 번역 API (추천: Gemini, 무료): 설정 > 자막 자동 번역에서 Gemini를 고릅니다.
  2. Google AI Studio에서 Create API key로 만든 키를 붙여 넣고 저장합니다.
  3. 로컬 AI (인터넷 없이): Gemma 4 E4B의 받기를 누릅니다(5.2GB). 다 받으면 사용 중으로 바뀝니다.

준비가 되면 한국어 자막이 없는 회차를 열기만 하면 됩니다. 보고 있는 장면부터 번역해 몇 초 뒤면 대사가 한국어로 바뀝니다.

  1. 위쪽 내 목록을 누릅니다.
  2. 다운로드 완료 탭에 받은 회차가 작품별로 모여 있습니다. 자막까지 그대로 나옵니다.
  3. 저장 폴더 바꾸기: 받은 파일을 외장하드로 옮겼다면 옮긴 폴더를 고르면 다시 이어집니다.
  1. LilacAnime 서버를 내 Vercel에 배포하고, Upstash Redis를 연결한 뒤 LILAC_PASSWORD(8자 이상)를 정합니다. 한 번만 하면 됩니다.
  2. 설정 > 기기 동기화를 엽니다.
  3. 서버 주소에 배포한 주소를 넣습니다.
  4. 비밀번호를 넣고 연결을 누릅니다. 휴대폰 앱에도 같은 주소와 비밀번호를 넣습니다.
