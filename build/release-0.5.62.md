## 플레이어

- 회차를 눌러 전체 화면으로 열 때 영상이 위아래로 튀던 문제를 고쳤습니다. 화면이 바뀌는 동안 플레이어가 작은 영역에 잠깐 그려졌다가 제자리로 돌아가던 것이 원인이었습니다.
- 윈도우 키, Alt, Ctrl, Shift를 누르거나 Alt+Tab, Win+D 같은 조합키로 창을 오갈 때 플레이어 조작 화면이 올라오지 않습니다. 다른 키는 전처럼 조작 화면을 띄웁니다.

## 화면

- 포스터 아래 그림자를 없앴습니다. 설정 > 일반의 "포스터 아래 그림자" 항목도 없어졌습니다. 홈 인기 순위 1위 카드는 제목이 그림 위에 있어서 제목 아래 그림자를 그대로 둡니다.

## 검증

- 자동 테스트 333개 통과.
