## RE:Anime

- RE:Anime가 새 주소(**reanime.cz**)로 옮겨 가면서 목록·검색·회차·재생이 모두 안 되던 문제를 고쳤습니다. 예전 주소(reanime.to)는 이제 어떤 요청이든 새 사이트의 첫 화면으로 보내서, 앱이 작품 정보 대신 웹페이지를 받고 있었습니다.
- 내 목록, 시청 기록, 이어서 보기, 다운로드한 회차, 저장한 자막은 그대로 이어집니다. 휴대폰과의 기기 동기화도 같은 회차로 맞춰집니다.

## 검증

- 자동 테스트 347개 통과. 새 주소에서 RE:Anime 회차를 실제로 열어 영상 조각까지 재생되는 것과 요일별 편성표를 확인했습니다.

## 다운로드
