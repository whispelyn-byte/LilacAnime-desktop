## 애니24

- 애니24가 새 주소(**a101.ohli24.com**)로 옮겨 가면서 목록·검색·회차·재생이 모두 안 되던 문제를 고쳤습니다. 예전 주소(ani.ohli24.com)는 이제 어떤 요청이든 "법적 사유로 이용 불가"(HTTP 451)로만 답합니다.
- 내 목록, 시청 기록, 이어서 보기, 다운로드한 회차는 그대로 이어집니다. 휴대폰과의 기기 동기화도 같은 회차로 맞춰집니다.
- 내 목록 **최근 업데이트순**에서 애니24 작품이 최신 회차가 나와도 맨 뒤에 남아 있던 문제도 함께 풀립니다(#33). 작품 페이지를 읽지 못해 최신 회차 날짜를 몰랐기 때문입니다.
- 목록 카드에 회차 수·장르·연도·극장판 표시가 빠지던 문제를 고쳤습니다. 사이트가 카드에 담는 정보의 형식을 바꿨습니다.

## RE:Anime

- RE:Anime 회차가 "영상 주소를 찾지 못했습니다 (응답 시간 초과)"로 재생되지 않던 문제를 고쳤습니다. FlixCloud 플레이어가 이제 다른 페이지 안(iframe)에서 열 때만 영상을 주고, 따로 열면 "파일을 찾을 수 없음"으로 답합니다. 앱도 RE:Anime 사이트처럼 플레이어를 페이지 안에 띄워 엽니다.
- 영상이 지워진 서버는 30초를 기다리지 않고 바로 다음 서버로 넘어갑니다.

## 검증

- 자동 테스트 350개 통과. RE:Anime 회차를 실제로 열어 영상·음성 조각까지 재생되는 것을 확인했습니다. 애니24는 새 주소에서 목록·필터·요일별 방영표와 회차 영상 조각까지 받아지는 것을 확인했습니다.
