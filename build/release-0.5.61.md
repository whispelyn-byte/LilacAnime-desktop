## 자막 자동 선택

- 다른 사이트(RE:Anime · Miruro · 애니24 · 링크애니 · Linkkf)의 같은 회차 한국어 자막과 블로그(Kairan · Csora · Anissia) 자막을 동시에 찾고, 2.5초 안에 나온 한국어 자막을 바로 띄웁니다. 둘 다 있으면 다른 사이트 자막을 먼저 씁니다. 전에는 다른 사이트 자막을 최대 16초까지 기다린 뒤에야 블로그 자막을 띄웠습니다.
- 지난번에 애니24 · 링크애니 · Linkkf에서 한국어 자막을 찾았던 작품은, 그 사이트 자막을 16초까지 기다립니다. 이 사이트들은 페이지를 읽어야 해서 자막이 늦게 옵니다.
- 번역 API로 하는 자동 번역은 요청을 쓰므로, 한국어 자막 찾기가 끝날 때까지(최대 16초) 기다렸다가 시작합니다. 로컬 AI 번역과 Whisper는 바로 시작합니다.
- 한국어 자막이 늦게 도착하면, 번역 자막 · Whisper 자막 · 일본어나 영어 자막이 떠 있거나 아무 자막도 없을 때 자동으로 바꿉니다. 바꿀 때는 플레이어 아래에 "한국어 자막을 찾아서 바꿨어요"와 되돌리기가 나옵니다.
- 직접 고른 자막(자막 소스 버튼, 자막 트랙, 내 자막 파일, 한국어 자막 제안의 바꾸기)과, 기계 번역으로 보는 작품의 자막은 바꾸지 않습니다.

## 검증

- 자동 테스트 333개 통과.
